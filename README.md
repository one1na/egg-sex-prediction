# 种蛋性别与发育预测：流程原型

用高光谱图像在孵化早期判断种蛋性别的一套训练和评估流程。

> **现状：只是流程原型。** 目前只在程序生成的模拟数据上验证过，并在一份公开的真实光谱（标签是受精与否，不是性别）上把流程跑通过。
> **这里没有任何真实种蛋的性别识别准确率**，模拟数据上的数字不代表真实效果。

## 这套流程做什么

- **按批次分组的交叉验证**：同一入孵批次的蛋不会同时出现在训练和验证里。
- **数据隔离检查**：训练前逐条核对所有划分，跨边界就停下；测试里人为制造泄漏，确认拟合步骤从不碰测试蛋。
- **独立测试集只看一次**：测试批次事先锁定，正式评估之后再运行会被拦下；看成绩之前先记下查看，中途崩溃也算看过，两个训练同时跑只有一个能看。
- **和传统方法同场比较**：深度模型（波段卷积 + 空间卷积 + GRU 时序）对事先指定的 PLS-DA 做唯一的正式检验，逻辑回归只作探索性比较；深度模型没有明显更好就部署 PLS-DA。
- **发布门控**：打乱标签自检和背景负对照分“通过 / 未通过 / 未执行 / 不适用”；没通过就不保存模型、不做独立测试。真实数据上没做的检查也拦下，必须先有一次代码和数据都对得上的自检。
- **消融实验**：每次去掉一个部件，只做交叉验证。
- **统计评估**：只有一个事先规定的主检验；逐日比较做 Holm 校正；概率校准、失败案例分析；重复交叉验证看结论对分折方式的敏感程度。
- **可追溯**：每次运行记下命令、git 提交号和代码指纹、数据指纹、依赖版本核对；固定随机种子并启用确定性算法。
- **两个界面**：桌面窗口和本机网页（图表、历史运行记录）。

## 运行

需要 Python 3.11，依赖见 `code/requirements.txt`（numpy、scipy、scikit-learn、torch，版本已锁定）。

Windows 上直接双击根目录的 `.bat` 文件；其他系统在 `code/` 里运行：

```bash
python export_sample.py                  # 生成样例数据（判断新蛋的默认输入）
python train_demo.py                     # 训练和评估（模拟数据）
python train_demo.py --shuffle-labels    # 流程自检
python predict.py                        # 判断新蛋
python web_app.py                        # 网页界面
python -m unittest discover -s tests     # 自动化测试
```

完整说明见 [使用说明.md](使用说明.md)。

## 数据

- 模拟数据由 `code/synth_data.py` 生成，性别信号是人为放进去的。
- `data/illinois_fertility/` 是伊利诺伊大学公开的种蛋高光谱数据的平均光谱（Illinois Data Bank，doi:10.13012/B2IDB-8141497_V1），标签是受精状态。数据归原作者所有，引用方式见其说明文件。
- `data/template/` 是采集真实数据时用的记录表模板。
